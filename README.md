# dynamic-bot-weibo

微博动态源插件，用于让 dynamic-bot 订阅微博用户的新动态，并支持解析微博链接。

主项目：[dynamic-bot](https://github.com/Colter23/dynamic-bot)

## 功能

- 登录微博账号（支持二维码和 Cookie）。
- 关注、取关微博用户，可选加入关注分组。
- 检测订阅用户的新微博并推送。
- 解析微博正文和用户链接，自动补全长文。
- 登录失效时自动暂停轮询，避免反复请求。

当前版本不支持用户名搜索，添加订阅时请使用微博 UID。

## 安装

构建插件：

```powershell
.\gradlew.bat fatJar --offline
```

把生成的 `*-all.jar` 放入主程序的 `plugins/` 目录，然后启动或重启 dynamic-bot，在后台启用插件。

## 登录

在后台的“平台登录”页登录微博账号，支持二维码和 Cookie 两种方式。

登录状态会被保存，重启后自动恢复。登录失效时轮询会暂停，重新登录后恢复；如果长时间仍未恢复，重启插件即可。

## 配置项

微博接口比较敏感，轮询默认关闭，需要推送动态时再开启。大多数情况保持默认即可。

- `启用轮询`：是否定时检测新微博，默认关闭。
- `轮询间隔`：多久检查一次，默认 60 秒。
- `请求间隔`：连续请求微博接口之间等待多久，默认 1 秒。
- `关注分组名` / `自动创建关注分组`：关注后加入哪个分组、分组不存在时是否自动创建。
- `未登录暂停阈值`：连续未登录几次后暂停轮询。
- `补发时间窗口`：启动时是否补发最近微博，默认 0（不补发）。

## 使用建议

- 不需要推送时保持轮询关闭。
- 不要把轮询间隔设得过短，容易触发风控。
- 出现风控或请求失败时，先暂停轮询或增大请求间隔。
- 插件通过微博关注流检测新动态，因此订阅的用户需要处于已关注状态。开启主程序的“订阅时自动关注”最省事。
